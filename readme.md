## About SportStack

SportStack is a point-of-sale and business-operations platform for sports organisations and retailers.

## Installation & Documentation
You will find installation guide and documentation in the downloaded zip file.
Project documentation is maintained in the repository's `docs` directory.

## Security Vulnerabilities

If you discover a security vulnerability within SportStack, report it privately to the SportStack maintainers. All security vulnerabilities will be promptly addressed.
